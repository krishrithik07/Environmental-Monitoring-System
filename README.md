# Environmental Monitoring System

**ESP32-C3 | LoRa Communication | KiCad PCB Design**

## Project Overview

This project focuses on designing an IoT-based Environmental Monitoring System using an ESP32-C3 microcontroller and LoRa communication.

The system integrates multiple sensors to monitor environmental conditions, including gas leakage, temperature and flame detection.

## Hardware Components

| Component | Purpose |
|---|---|
| ESP32-C3 | Main Controller |
| LoRa RA-02 | Wireless Communication |
| MQ-2 | Gas Detection |
| MQ-4 | Methane Detection |
| MQ-7 | Carbon Monoxide Detection |
| Temperature Sensor | Temperature Monitoring |
| Flame Sensor | Flame Detection |
| LM2576T-5.0 | 5V Power Regulation |
| LM2576T-3.3 | 3.3V Power Regulation |

## Design Tools

- KiCad – Schematic Capture and PCB Design
- ESP32-C3 – Embedded Controller
- LoRa – Wireless Communication

## Project Architecture

The system consists of a main controller and multiple sensor nodes. Sensor data is collected and communicated wirelessly through LoRa.
